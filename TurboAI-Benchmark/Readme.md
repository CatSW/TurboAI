# Istruzioni

- Copiare il folder `TurboAI-Benchmark` in un nuovo folder esempio `TurboAI-Benchmark-Grok_4_6-turboai_1_0_4`
- Copiare la cartella .turbo-ai da testare nel folder 
- eseguire da `<folder-solution-benchmark>/.turbo-ai/` il comando aaa-startup-llm-session.cmd
- svolgere il piano (`.ai-context/Piano-Multi-Task.md`)
- generare il report di valutazione a fine esecuzione del piano
