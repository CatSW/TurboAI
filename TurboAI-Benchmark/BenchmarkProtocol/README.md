# TurboAI Benchmark Evidence Protocol

Formal cross-model execution starts only after the TurboAI evolution readiness gate in governance is complete.

## Execution modes

- `B_ONLY`: one Channel B participant performs governance and execution.
- `A_PLUS_B`: Channel B owns governance, verification and closure; Channel A executes assigned tasks.

The report records only the current independent run. Later comparison uses the final reports from separate clean runs.

## Indicative manual count

At the end of the plan, the benchmark analysis script may count trimmed lines beginning with `User:` case-insensitively in the single optional manual file associated with the run. The report includes one count and a link to that source. Missing evidence is `not recorded`; multiple candidate files are ambiguous and are not summed.
